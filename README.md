# zwatch
watch for macOS implemented in zsh

Just drop this into your personal bin directory.

I didn’t like how watch builds on macOS couldn’t handle unicode/UTF-8, and how MacPorts doesn’t understand macOS ncurses compatibility (no, you don’t actually need ncurses 6.6 installed in /opt/local for a lot of MacPorts to function).

Could I have hacked on the watch binary? Yeah.

Will I add zcurses and expand it? Of course.

Will I create a man page? You bet.

But this does what I need it to do right now, and it might be useful to others.
